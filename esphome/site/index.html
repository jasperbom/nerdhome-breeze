Nerdhome Breeze

Lokale ESPHome-wifi-adapters voor airco's. Kies je variant, sluit het printje met USB-C aan en installeer.

Installeren vanuit de browser

  1. Haal het printje los van de airco en sluit het met USB-C aan op deze computer.
  2. Klik op de knop van jouw variant en kies de seriële poort (USB JTAG/serial debug unit).
  3. Vul na het flashen meteen je wifi in. Home Assistant vindt de adapter daarna vanzelf.

Breeze voor Toshiba

Voor Toshiba-binnenunits met een CN22-wifiaansluiting (Shorai, Seiya, Haori, ...).

Gebruik Chrome of Edge op een computer om te flashen. Open deze pagina via https om te flashen.

Breeze voor Daikin

Voor Daikin-binnenunits met een S21-aansluiting (Emura, Perfera, Stylish, Sensira, ...).

Gebruik Chrome of Edge op een computer om te flashen. Open deze pagina via https om te flashen.

Let op

Sluit USB nooit aan terwijl het printje op de airco zit. Updates gaan daarna via wifi: Home Assistant toont een update-entiteit Firmware zodra hier een nieuwe versie staat.

Eigen config

Liever je eigen naam, API-sleutel of extra's? Neem de adapter over in de ESPHome Builder (Take control). Je krijgt dan een kleine YAML die breeze-toshiba.yaml of breeze-daikin.yaml uit de repository van GitHub haalt.
